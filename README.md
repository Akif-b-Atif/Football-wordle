# Footle — Football Wordle

[Play Footle](https://footle-pi.vercel.app/)

Footle is a daily footballer-guessing game: identify the hidden player in eight
tries using nationality, club, position, age, EA FC ratings and PlayStyles. It
was made for fun, as a football-themed guessing game.

> **Dataset:** EA SPORTS FC 27 men's player ratings, snapshot from
> **12 September 2026**. I’ll update it when I can, if I’m still maintaining
> Footle. Clubs and ratings can change after the snapshot.

## Player data and attribution

The source is [EA SPORTS FC 27 Player Ratings on Kaggle](https://www.kaggle.com/datasets/mikedpad/ea-sports-fc27-player-ratings)
by **MikeDPad**. The downloaded source CSV is `data/players_raw.csv`; the
cleaned runtime database is `data/players.csv`, generated by
`data/cleaner.py`.

The snapshot contains 19,789 men's and women's players. The cleaner keeps the
17,849 men's records and all included leagues, removes incomplete or duplicate
records, derives age as of the snapshot date, maps nationalities to
continents, and sorts players by overall rating. The generated CSV contains
only the fields Footle uses.

The Kaggle dataset page describes the data as an unofficial snapshot of EA's
ratings API for non-commercial educational and research use. Player names and
ratings belong to EA. This project is educational and non-commercial; the
source dataset is credited above.

## How the game works

- All cleaned players can be guessed. The daily and unlimited answers are
  chosen from the first 200 players in the rating-sorted CSV. This keeps
  answers to highly rated, relatively recognizable players while leaving the
  full men's dataset searchable. Change the cutoff with `ANSWER_POOL_SIZE`.
- Daily Challenge uses the same deterministic answer for everyone each UTC
  day. Unlimited mode picks a random answer from the same pool.
- Game state is carried in a signed JWT; no account, database, or sticky
  server session is needed.
- Each guess returns clue feedback: green is exact, yellow is close, and gray
  is not close.
  - **Nationality:** same country is green; another country on the same
    continent is yellow.
  - **Club:** same club is green; a different club in the same league is
    yellow.
  - **Position:** same position is green; another position in the same broad
    group (attack, midfield, or defence) is yellow.
  - **Age:** within two years is yellow. Ages are calculated as of the
    dataset snapshot date.
  - **Overall rating (OVR):** within two rating points is yellow.
  - **Skill Moves and Weak Foot:** these 1–5 star ratings are within one star
    to be yellow; arrows show whether the answer's rating is higher or lower.
  - **PAC, SHO, PAS, DRI, DEF and PHY:** each is within three rating points
    to be yellow. These six clues are collapsed under the **Stats** button in
    the OVR tile so the guess board stays readable on phones and desktops.
  - **Shared PlayStyles:** only PlayStyles shared by the guess and answer are
    shown.
- Numeric clues show an arrow indicating whether the answer's value is higher
  or lower. Tooltips and screen-reader descriptions explain every clue.
- Player names use the dataset's `common_name` for the short label when
  present, otherwise the last name. Long names follow
  `first_name "common_name" last_name` when a common name exists, and
  `first_name last_name` otherwise.
- Search ignores accents and punctuation and ranks better-rated players
  first.
- Completed games show the answer, a spoiler-free emoji result and browser-
  stored statistics. Daily Challenge and Unlimited stats are separate.

## Run locally

Requires Node.js 18+ and Python with pandas.

```bash
npm install
cp .env.example .env     # optional; set JWT_SECRET before public deployment
python data/cleaner.py   # regenerate players.csv from players_raw.csv
npm start
```

Open http://localhost:3000.

The frontend is plain HTML, CSS and JavaScript in `public/`; no build step is
needed. The Express backend in `server.js` loads `data/players.csv` into
memory, serves the frontend, searches players, and evaluates guesses.

## Updating the dataset

Replace `data/players_raw.csv` with a later export that has the source fields
used in `RAW_COLUMNS` in `data/cleaner.py`, then run:

```bash
python data/cleaner.py
```

The cleaner filters to men's football and all source leagues, drops players
missing a required game field, and fails with a list if a nationality needs a
continent mapping. Review the generated player count, names, and answer-pool
ratings before deploying. Update the snapshot date in this README and in the
dataset note in `public/index.html` when publishing a newer snapshot. Also
update `DATASET_VERSION` in `server.js` so game tokens from the previous
snapshot are invalidated instead of resuming against different player IDs.

The runtime CSV has exactly these columns:

| Column | Used for |
|---|---|
| `player_id` | EA player ID and guess/session identity |
| `short_name`, `long_name` | Display and accent-insensitive search |
| `primary_position` | Position clue |
| `overall` | OVR clue and answer-pool ordering |
| `age` | Age as of the snapshot date |
| `club_name`, `league_name` | Club clue and same-league feedback |
| `nationality_name`, `nationality_continent` | Nationality clue |
| `skill_moves`, `weak_foot` | 1–5 star rating clues |
| `playstyles` | Shared PlayStyles (comma-separated) |
| `pace`, `shooting`, `passing`, `dribbling`, `defending`, `physicality` | Expandable attribute clues |

## Environment variables

| Variable | Default | Purpose |
|---|---|---|
| `JWT_SECRET` | `dev-secret-change-me` | Signs game tokens. Set a long random value in production. |
| `PORT` | `3000` | Local server port; most hosts set this automatically. |
| `DATA_FILE` | `./data/players.csv` | Path to the cleaned player CSV. |
| `ANSWER_POOL_SIZE` | `200` | Number of highest-rated players eligible as answers; all records remain guessable. |
| `ALLOW_ORIGIN` | unset | CORS origin, only needed when hosting the frontend separately. |

## Project details

- `server.js` — Express API, CSV loading and comparison logic.
- `data/players_raw.csv` — source FC 27 snapshot.
- `data/players.csv` — generated game-ready player data.
- `data/cleaner.py` — data preparation and nationality-to-continent mapping.
- `public/` — static game interface.
